# MFES-2026 电影多维评价体系

MFES-2026（Multidimensional Film Evaluation System 2026）是一套公开、可审计、可复算的电影多维加权评价体系，以"一体两翼"为架构：**本体翼**（九板块，500 分）评价影片本身的品质，**价值翼**（八板块，300 分）体现中国特色社会主义发展观，**文明翼**（四板块，200 分）落实人类命运共同体理念。全部 71 项指标采用"全量程五级锚定制"（0–10 分五档公开标准＋档内微调），打分必须附证据。

- 版本：v1.1（2026 年 10 月；白皮书 v1.1 与配套论文 v1.7 对齐）
- 作者：康宁（北京电影学院电影学系副研究员）
- 许可证：[CC BY 4.0](LICENSE.txt)（署名 4.0 国际许可——任何人可引用、可复算、可改编，但须署名）
- 定位声明：本体系是研究者提出的**学术研究与行业参考工具**，不构成任何官方标准。

## 快速开始：复算四案例

```bash
python recompute_cases.py
```

脚本读取 `output/cases_board_scores.csv`，独立重算四部影片的三轨得分、加权总分与等级，并与白皮书公布值核对（《霸王别姬》856、《给阿嬷的情书》819、《流浪地球2》809、《功夫女足》560）。任何人均可据此验证：换一台机器、换一个实现，结论不变。

## 反馈与挑战

评价体系的公信力来自公开接受挑战。请通过 GitHub Issues 提交：指标锚定与微调点的合理性、权重设置、试评数据的证据质量、复算结果不一致等，均欢迎提出。每个 issue 将按"接受—修订—记录"流程处理，修订见 CHANGELOG。

## 使用范围提示

- 学术研究、教学与个人非商业使用：自由使用（署名即可）；
- 评奖、资助评审与社会效益考核等制度化场景：请先阅读白皮书第九节"限度声明"，v1.0 仅作为讨论稿；
- 商业服务：请联系作者协商。
